# QA session 2026-06-07

## ProviderManager status

`ProviderManager\Launch GUI.bat` открывает не tkinter GUI, а окно командной строки, которое показывает меню DeepSeek (`==== Меню ====`) вместо графического управления. Окно командной строки подтверждает, что node-сервер стартовал, но не дает подключаться через кнопки GUI.

## Failures

- Qwen отваливается при старте из GUI. Лог указывает на `qwen_light_proxy.py:314` и `FastAPI` в окружении, где эта версия несовместима с текущим `FastAPI`/`starlette`.
- В ответах DeepSeek есть `watermark: t.me/forgetmeai`. GUI не скрывает этот авторский маркер из строки статуса/здоровья.

## Workaround

- Прямой запуск `node server.js` для DeepSeek работает.
- Перелогин DeepSeek через PowerShell с переменными окружения работает.
